Aplique o método desta edição em [Estratégia e processo de marketing](./references/zaip/marketing.md), [Análise de dados e indicadores](./references/zaip/dados.md). Consulte as decisões e fontes vigentes da equipe para este projeto.

Identifique qual conjunto de dados é o destino esperado e onde o código dispara cada evento. Verifique nome de evento, chave de ocorrência e emissões repetidas por navegação ou clique. Rastreie o par Pixel e servidor separadamente e respeite consentimento.

Para um único lead, confira se as duas vias compartilham a chave e se um novo lead recebe outra. Relate emissão local, aceitação pelo destino, deduplicação e atribuição apenas quando observadas. Um Pixel instalado por si só não valida uma compra.
