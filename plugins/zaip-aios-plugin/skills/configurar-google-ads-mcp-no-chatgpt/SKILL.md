# Configurar o Google Ads no ChatGPT Work

Use esta skill para instalar o conector web ou orientar a pessoa na integração. Se ela pedir um passo a passo, explique o fluxo abaixo. Para executar o cadastro, use Computer Use na aba existente do ChatGPT e confira o workspace. Se faltar a aba, peça que a pessoa abra o ChatGPT no navegador, entre no workspace desejado e avise. Se o acesso à aba for recusado, informe a permissão pendente e aguarde. Para analisar resultados de um conector já funcional, use a skill `analisar-campanhas-google-ads`.

## Escolher e instalar o conector

1. Em **Plugins**, procure primeiro nos instalados. Abra a ficha e confira o provedor, o destino Google Ads e as ferramentas de campanha disponíveis. Reutilize uma integração compatível com leitura e edição. Se houver somente relatórios, preserve o vínculo e explique qual função falta. Uma ficha só para desktop ou para anúncios do próprio ChatGPT atende a outro destino.
2. Para começar pelo catálogo, procure **AdKit - Ads Manager**, desenvolvido por **AdKit**. Explique que esse fornecedor externo intermedeia o acesso ao Google Ads e exige uma conta AdKit. O plugin do catálogo oferece várias redes. Se escolhido, abra a ficha, clique em **Instalar** quando necessário e use apenas a conexão Google Ads. [Ficha do plugin no ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6a1e848decdc8191a4974b315c51661f)
3. Se a pessoa preferir expor apenas ferramentas do Google Ads, use o servidor do mesmo fornecedor. Confira se já existe uma entrada web para `https://mcp.adkit.so/google-ads`. Na ausência, abra **Plugins → + → Adicionar servidor MCP personalizado**. Sugestão de nome: **Google Ads MCP – Gestão ZAIP-AIOS (AdKit)**. Informe o endereço HTTPS completo acima, selecione **OAuth** e use o registro dinâmico se oferecido pela descoberta. Confira o domínio, revise as permissões e selecione **Criar como plugin**. Instale se a interface solicitar. Se a criação demorar, confira a lista antes de repetir. Se faltar acesso para cadastrar o servidor ou usar ações de escrita, identifique a restrição para o administrador do workspace. [Servidor Google Ads do AdKit](https://github.com/adkit/google-ads-mcp#chatgpt) · [Cadastro de servidor no ChatGPT](https://developers.openai.com/apps-sdk/deploy/connect-chatgpt)
4. Ao exibir **Conectar**, encerre o cadastro e entregue a aba à pessoa. Se o OAuth abrir automaticamente, pare nessa tela. A pessoa entra no AdKit, escolhe o projeto e a conta cliente do Google Ads e revisa o consentimento no navegador. Preserve vínculos existentes. Nunca solicite senha, token ou segredo no chat. Para este fluxo com o AdKit, o usuário não precisa criar uma chave da API da OpenAI.

## Testar depois do vínculo

- **Leitura.** Em um novo chat do mesmo workspace, selecione o plugin pelo menu `@`. Peça: “Na conta cliente que eu indicar, liste até cinco campanhas com ID, nome e status. Mostre custo e cliques dos últimos sete dias completos, com moeda e fuso.” Se for uma conta gerenciadora, confirme o ID do cliente anunciante. Resultado vazio no período também é um resultado válido.
- **Edição em rascunho.** Confira se a lista de ferramentas expõe leitura e atualização de campanhas. No servidor AdKit, procure `google_ads_campaigns_read` e `google_ads_campaigns_update`. Em uma campanha de teste já identificada, peça: “Prepare só um rascunho para renomear a campanha de A para B. Mostre conta, ID, nome atual, nome proposto e identificador ou link do rascunho.” Confira os campos e o estado do rascunho antes de afirmar que a edição está disponível. [Ferramentas e aprovação do AdKit](https://github.com/adkit/google-ads-mcp#tools)
- **Publicação.** Faça o teste de instalação até o rascunho. Para aplicar uma mudança real pedida depois, mostre a conta, a campanha, a diferença e qualquer efeito sobre veiculação ou verba. Aguarde aprovação explícita desse rascunho. Após a publicação, releia a campanha pelo ID. Se a resposta expirar, confira o rascunho e o estado no Google Ads antes de repetir.
- **Quando só a leitura funcionar.** Confira a ação habilitada no workspace, o projeto vinculado no AdKit e o acesso de edição da pessoa à conta cliente do Google Ads. Se a pessoa preferir infraestrutura própria, o Google documenta a hospedagem do seu MCP com OAuth e operações específicas de ativos e rótulos. Verifique se ele oferece a edição de campanha desejada. Para campos ausentes, uma implementação própria pode expor uma ação delimitada da Google Ads API, como `CampaignService.MutateCampaigns` para mudar o status. [MCP do Google](https://developers.google.com/google-ads/api/docs/developer-toolkit/mcp-server) · [Exemplo de atualização da Google Ads API](https://developers.google.com/google-ads/api/samples/update-campaign)
